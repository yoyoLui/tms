## 流程 1 · 主营业务闭环：客户下单 → 完成交付（最核心）

```mermaid
sequenceDiagram
    autonumber
    participant 客户 as 货主/客户
    participant 销售 as 销售/业务员
    participant 调度 as 调度员
    participant 司机 as 司机(APP)
    participant 财务 as 财务
    participant IoT as ⚠️ 温度系统

    客户->>销售: 提出运输需求
    销售->>销售: 录入「订单」（货物/起止地/时间/金额）
    Note over 销售: 一个订单可拆出多个运单
    
    销售->>调度: 提交调度
    调度->>调度: 创建运单（关联订单/货物/路线）
    调度->>调度: 派车（分配司机+车辆+挂车）
    
    alt 长途/多段
        调度->>调度: 分段运输：每段单独分配运力
    end
    
    alt ⚠️ 冷链预冷
        调度->>司机: 推送派车单(含预冷要求)
        司机->>司机: APP 查看预冷要求
        司机->>温度系统: 启动预冷流程
        温度系统->>司机: 预冷完成，通知司机
        司机->>调度: APP 中确认「预冷已达标」
    else ⚠️ 普通流程
        调度->>司机: 推送派车单
    end
    
    司机->>司机: APP 接单、查看运单详情
    司机->>司机: 装货：上传装车凭证（磅单/照片）
    
    alt ⚠️ 冷链装卸断链
        司机->>温度系统: 标记「装卸开始」
        Note over 司机,温度系统: 此期间的温度异常<br/>不计入超温
    end
    
    司机-->>调度: 装货完成，开始在途
    
    Note over 司机,温度系统: 在途期间<br/>- 温度实时采集<br/>- 超温自动告警<br/>- 司机可一键响应
    
    alt ⚠️ 冷链超温告警
        温度系统->>司机: 🚨 超温告警
        司机->>司机: APP 中「确认异常」或「上报处理」
        温度系统->>调度: 通知调度员
        温度系统->>财务: 通知财务（可能影响计费）
    end
    
    alt ⚠️ 冷链在途费用
        司机->>司机: 上报费用（油费/ETC/尿素/现金）
    else 普通在途费用
        司机->>司机: 上报费用（修车/违章/停车等）
    end
    
    司机->>司机: 抵达卸货点
    
    alt ⚠️ 冷链卸货断链
        司机->>温度系统: 标记「卸货开始」
        温度系统->>温度系统: 卸货期间温度异常不计入
        司机->>温度系统: 标记「卸货完成」
    end
    
    司机->>司机: 卸货：上传卸车凭证
    司机->>司机: 标记「运输完成」
    司机->>司机: 上传纸质回单照片
    
    调度->>调度: 审核回单，运单关闭
    
    alt ⚠️ 冷链温度合规留档
        温度系统->>温度系统: 温度数据不可篡改存储（5 年）
        温度系统->>财务: 生成温度证书（用于对账）
    end
    
    调度->>财务: 触发结算
    财务->>财务: 应付核算：给司机/车队/外协结算
    
    alt ⚠️ 冷链质量异议
        财务->>财务: 检查是否有超温记录
        alt 超温导致货损
            财务->>财务: 创建「质量异议」状态
            财务->>司机: 通知扣款
        end
    end
    
    财务->>财务: 应收核算：给货主生成账单
    财务->>客户: 申请开票 → 收款核销
```

### 🔑 关键节点解析

| 节点 | 普通物流 | 冷链物流（改造点） |
|---|---|---|
| ① 订单录入 | 记录基本信息 | **加字段**：温度要求、合规等级 |
| ② 运单生成 | 拆分运单 | **加关联**：温度阈值、预冷计划 |
| ③ 派车 | 分配司机/车 | **检查**：车辆是否满足温区要求 |
| ④ 预冷（**新增**） | N/A | **冷链独有**：司机必须完成预冷并确认 |
| ⑤ 装货 | 拍照确认 | **新增**：标记装卸开始，温度断链豁免开始 |
| ⑥ 在途 | 上报费用 | **全程贯穿**：温采、告警、司机响应 |
| ⑦ 卸货 | 拍照确认 | **新增**：标记卸货结束，断链豁免结束 |
| ⑧ 完成交付 | 上传回单 | **新增**：生成温度证书、合规留档 |
| ⑨ 结算 | 应付应收 | **改造**：加质量异议流程、超温扣款规则 |

## 流程 2 · 司机端 APP 作业流程

```mermaid
flowchart TD
    A[司机登录 APP] --> B{今日是否有派车}
    B -->|有| C[查看运单列表]
    B -->|无| D[查看通知/审批/个人信息]
    
    C --> E[选中运单查看详情]
    E --> F{⚠️ 是否为冷链运单}
    
    F -->|是| G["⚠️ 查看温度要求<br/>- 温度范围<br/>- 预冷要求<br/>- 温区类型"]
    F -->|否| H[到达装货点]
    
    G --> I["⚠️ 预冷确认<br/>1. 启动预冷机<br/>2. 等待达标<br/>3. APP 中确认<br/>（不确认无法出发）"]
    I --> H
    
    H --> J[扫码/拍照确认货物]
    J --> K["⚠️ 标记装货开始<br/>（温度断链豁免开始）"]
    K --> L[上传装货凭证]
    L --> M[标记装货完成 → 开始在途]
    
    M --> N{在途事件}
    
    N -->|消费油费| O["上报费用<br/>- 油卡/现金/ETC<br/>- 尿素<br/>- 其他"]
    N -->|现金不够| P[提交现金出车款申请]
    
    N -->|⚠️ 温度告警| Q["🚨 冷链告警处理<br/>- 看温度值<br/>- 一键「确认异常」<br/>- 或「上报处理」<br/>（实时通知调度/质控）"]
    
    O --> R[继续在途]
    P --> R
    Q --> R
    
    N -->|⚠️ 预冷失败| S["❌ 预冷异常<br/>- 可选择返回<br/>- 或继续运输<br/>（标记异常）"]
    S --> R
    
    N -->|抵达卸货点| T["⚠️ 标记卸货开始<br/>（温度断链豁免开始）"]
    T --> U[卸货并上传凭证]
    U --> V["⚠️ 标记卸货完成<br/>（温度断链豁免结束）"]
    
    V --> W[标记「运输完成」]
    W --> X[上传纸质回单照片]
    
    X --> Y{⚠️ 是否冷链运单}
    Y -->|是| Z["⚠️ 下载温度证书<br/>（可用于客户对账）"]
    Y -->|否| AA["运单进入结算流程"]
    
    Z --> AA
    
    style I fill:#fff4e6,stroke:#ff8c00,stroke-width:2px
    style K fill:#fff4e6,stroke:#ff8c00,stroke-width:2px
    style Q fill:#ffe6e6,stroke:#ff0000,stroke-width:2px
    style T fill:#fff4e6,stroke:#ff8c00,stroke-width:2px
    style Z fill:#e6f3ff,stroke:#0066ff,stroke-width:2px
```

### 💡 冷链 APP 设计要点

| 操作点 | 设计细节 |
|---|---|
| **预冷确认** | 非强制完成不能开始运输；记录预冷时间、最终温度 |
| **温度查看** | 实时显示各温区温度、曲线图、与阈值对比 |
| **告警响应** | 告警时弹出"确认/上报"对话框，自动记录响应时间 |
| **断链标记** | 装卸开始/结束时一键标记，系统自动豁免这段时间的超温 |
| **费用上报** | 支持拍照、金额输入、多笔汇总 |
| **温度证书** | 完成后可下载包含"时间/温度/异常"的 PDF 证书 |

## 流程 3 · 自有车成本管理流程

```mermaid
flowchart LR
    subgraph 期初["📅 期初设置（如 2026-01-01）"]
        A1["录入车辆基本信息<br/>• 车牌<br/>• 购买日期<br/>• 费用确认日期"]
        A2["设置现金期初期末"]
        A3["设置油卡期初期末"]
    end
    
    subgraph 期间["📊 日常运营（2026-01 ~ 2026-12）"]
        B1["费用分类维护<br/>（系统配置）"]
        B2["司机/财务录入费用<br/>• 收入：现金/油卡<br/>• 支出：现金/油费/ETC/尿素"]
        B3["财务审核单条费用<br/>（逐笔或批量）"]
        B4["费用关联运单<br/>支持批量关联<br/>（每条费用知道来自哪一单）"]
    end
    
    subgraph 期末["📈 结账分析（2026-12-31）"]
        C1["费用列表查询<br/>• 已审核/未审核<br/>• 按日期/类型筛选"]
        C2["自有车报表<br/>• 成本汇总<br/>• 油卡使用比例<br/>• 单运单成本分析"]
        C3["车辆利润核算<br/>（总收入-总成本=利润）"]
    end
    
    期初 --> 期间 --> 期末
    
    B4 -.精确成本核算.-> C3
    
    style B4 fill:#ffe4b5,stroke:#ff8c00,stroke-width:2px
    style C3 fill:#b5ffd9,stroke:#00bb00,stroke-width:2px
```

### 🎯 冷链改造点

| 改造点 | 原因 |
|---|---|
| **冷藏机组油费单独类目** | 冷链车的发动机油和冷藏机组油要分开计，冷链机组油费才是核心成本 |
| **制冷能耗监控** | 可选：按温区/按车/按时段统计冷藏机组油费 |
| **超温处理费** | 新增费用类目：温度异常导致的处理、客户索赔、品质补偿等 |

## 流程 4 · 应收账款流程

```mermaid
stateDiagram-v2
    [*] --> 待核算: 运单完成

    待核算 --> 已核算: 财务审核<br/>检查费用合理性<br/>⚠️ 检查超温记录
    
    已核算 --> 待开票: 申请开票
    
    待开票 --> 已开票: 开票完成<br/>生成发票
    
    已开票 --> 已收款: 收款核销<br/>记录收款方式/日期
    
    已收款 --> [*]
    
    待核算 --> 已退回: 核算失败<br/>（单据有问题）
    
    已退回 --> 待核算: 修正后重新提交
    
    alt ⚠️ 冷链质量异议
        已核算 --> 质量异议待处理: 客户拒收/扣款<br/>（超温/货损）
        质量异议待处理 --> 质量异议已处理: 协商/赔付
        质量异议已处理 --> 已开票: 确认最终金额
    end
    
    note right of 已核算
        财务工作：
        - 核对运费/装卸费/过路费
        - ⚠️ 检查温度证书
        - ⚠️ 检查是否有质量异议
        - 确认最终金额
    end note
```

### 💼 冷链改造说明

- **冷链新增状态**：「质量异议待处理」→ 处理超温导致的客户拒收或扣款
- **应收冻结**：如果发现严重超温且客户标记异议，应收可暂时冻结等待协商
- **温度证书关联**：每一笔应收单都应关联运单的温度记录

## 流程 5 · 应付账款流程（给司机/外协）

```mermaid
stateDiagram-v2
    [*] --> 待付款: 运单完成<br/>司机/外协应得

    待付款 --> 已审核: 财务审核<br/>检查费用合理性<br/>⚠️ 检查超温扣款规则
    
    已审核 --> 已付款现金: 现金支付
    已审核 --> 已付款油卡: 油卡支付
    
    已付款现金 --> [*]
    已付款油卡 --> [*]
    
    alt ⚠️ 冷链超温扣款
        已审核 --> 应付单驳回: 发现严重超温<br/>需要扣款
        应付单驳回 --> 已调整: 按规则调整金额
        已调整 --> 已审核: 重新审核
    end
    
    note right of 已审核
        审核维度：
        - 单价正确性
        - 在途费用合理性
        - 是否对应有效运单
        - ⚠️ 超温时长判断
        - ⚠️ 是否触发扣款规则
    end note
```

### ⚠️ 冷链改造说明

| 改造点 | 说明 |
|---|---|
| **超温扣款规则** | 运单中可配置：超温多少时长开始扣款、扣款比例、最高扣款额 |
| **质量责任判定** | 如果超温导致客户拒收，应付可按比例扣款给司机 |
| **驾驶员告警记录** | 频繁超温的司机，系统可自动预警或降低计费等级 |

## 流程 8 · 流程审批引擎（横切能力）

```mermaid
flowchart LR
    A["业务单据提交<br/>• 运单<br/>• 应付/应收<br/>• ⚠️ 温度异常处理<br/>• ⚠️ 质量异议<br/>• 在途费用<br/>• 其他"]
    
    B{"是否需要<br/>审批"}
    
    C["创建流程实例"]
    D["流程任务派发<br/>给指定审批人<br/>（支持多级）"]
    
    E{"审批人<br/>决策"}
    
    F["下一节点<br/>（如果有）"]
    G["退回发起人<br/>修改后重新提交"]
    H["转他人<br/>改派给其他审批人"]
    
    I{"是否<br/>最终节点"}
    
    J["流程结束<br/>业务单据生效"]
    K["流程任务记录"]
    
    A --> B
    B -->|是| C
    B -->|否| J
    
    C --> D
    D --> E
    
    E -->|同意| F
    E -->|驳回| G
    E -->|转他人| H
    
    H -.改派后.-> D
    G -.修改后.-> D
    
    F --> I
    I -->|否| D
    I -->|是| J
    
    D -.所有操作.-> K
    
    style D fill:#ffe4b5,stroke:#ff8c00,stroke-width:2px
    style J fill:#b5ffd9,stroke:#00bb00,stroke-width:2px
```

### 🔧 冷链特需的审批场景

| 审批场景 | 审批链 | 备注 |
|---|---|---|
| **温度异常处理** | 质控员 → 财务 → 客服（通知客户） | 严重超温时自动触发 |
| **质量异议** | 客服 → 质控 → 财务 | 客户投诉时手动创建 |
| **应付扣款** | 司机 → 财务主管 | 确认是否合理扣款 |
| **合规留档审批** | 合规审计员 | 确认温度数据是否可归档 |

## 流程关键指标追踪（仪表板）

### 🎯 支撑流程 1 的指标

| 指标 | 频率 | 计算逻辑 |
|---|---|---|
| **日订单数** | 日 | COUNT(订单) WHERE 日期 = TODAY |
| **日运单数** | 日 | COUNT(运单) WHERE 创建日期 = TODAY |
| **平均派车时间** | 日 | AVG(派车时间 - 订单创建时间) |
| **完成率** | 日 | COUNT(已完成运单) / COUNT(总运单) |
| **⚠️ 超温率** | 日 | COUNT(有超温告警的运单) / COUNT(冷链运单) |
| **⚠️ 质量异议率** | 日 | COUNT(质量异议) / COUNT(应收单) |

### 📊 支撑流程 2 的指标

| 指标 | 频率 | 说明 |
|---|---|---|
| **司机在线率** | 实时 | 有活跃运单的司机数 / 总司机数 |
| **⚠️ 预冷完成率** | 日 | COUNT(预冷已确认) / COUNT(应预冷运单) |
| **装卸时长** | 运单级 | 装卸结束时间 - 装卸开始时间 |
| **⚠️ 告警响应时间** | 实时 | 告警 → 司机点击「确认」的时间差 |

# 50 个关键反问清单 · 冷链物流管理系统

> **使用说明**：把这份文档（或下面的「业务方答复记录」模板）直接发给你朋友，约 **2-3 次访谈、每次 1.5 小时** 走完。  
> **每个问题都标注了「为什么问 / 不问的代价 / 参考答案」**，你访谈时可以直接照着念。  
> **重要等级**：⭐⭐⭐ = 不问会出大事；⭐⭐ = 不问会返工；⭐ = 可以延后但要记录假设。

---

## A. 业务背景与商业模式（8 题）

### A1 ⭐⭐⭐ 公司目前的定位是什么？
- **问法**：贵公司在冷链物流链条里扮演什么角色？是 ① 自有车队的承运方 ② 货主方（自有冷链需求） ③ 平台撮合方（无车无货） ④ 还是三方综合服务商？
- **为什么问**：决定整个系统的"主视角"。承运方系统重在调度，平台方重在撮合，货主方重在追溯。
- **不问的代价**：做出来的系统主菜单/工作台完全错位。
- **参考答案**：[ ] 承运方　[ ] 货主方　[ ] 平台方　[ ] 综合

### A2 ⭐⭐⭐ 公司当前业务规模
- **问法**：① 自有 / 合作 / 外协冷藏车各多少辆？② 月均订单量？③ 月营收量级？④ 员工数（含司机）？
- **为什么问**：决定数据库容量规划、并发设计、是否需要分布式架构。
- **参考答案**：车辆 ___ 辆 / 月单量 ___ / 月营收 ___ 万 / 员工 ___ 人

### A3 ⭐⭐⭐ 主营货品品类
- **问法**：主要运什么？请按比例列：① 生鲜（果蔬肉禽水产）② 速冻食品 ③ 乳制品 ④ 医药 ⑤ 疫苗 / 生物制品 ⑥ 化工/危化 ⑦ 鲜花 ⑧ 其他
- **为什么问**：决定**温度区间、合规级别、报警严苛度、是否需要 GSP/疫苗法合规**——这是冷链系统最关键的变量。
- **不问的代价**：医药冷链漏做 GSP 直接违法；生鲜系统硬塞医药客户搞不定温控。

### A4 ⭐⭐ 服务半径与运输类型
- **问法**：① 同城配送 ② 城际短途（500km 内） ③ 干线长途 ④ 跨省全国，各占比？
- **影响**：决定地图调度算法、司机排班模型、是否需要中转仓。

### A5 ⭐⭐ 客户构成
- **问法**：B 端大客户（电商/连锁/工厂） vs 中小企业客户 vs C 端散单，各占比？前 10 大客户贡献多少营收？
- **影响**：决定是否要做客户分级、SLA 管理、对接客户 ERP 的优先级。

### A6 ⭐⭐⭐ 当前用什么系统/工具？
- **问法**：① 完全 Excel/微信群？② 有旧系统（叫什么？谁开发的？）？③ 用了第三方 SaaS（如 G7、智慧货运）？
- **为什么问**：决定 **① 数据迁移工作量 ② 用户使用习惯（直接照搬还是改造） ③ 是否需要兼容/替换**。
- **不问的代价**：上线后老员工拒绝用，项目失败。

### A7 ⭐ 与上下游的对接情况
- **问法**：是否对接电商平台（淘宝/京东/美团）的订单？是否给货主开放查询接口？是否对接客户 WMS / ERP？
- **影响**：决定 API 网关、SSO、第三方对接的工作量。

### A8 ⭐ 长约 vs 临单比例
- **问法**：固定合约客户 vs 临时单的比例？是否有竞价/抢单业务？
- **影响**：决定是否要做"运力交易市场"功能。

## B. 用户角色与组织架构（6 题）

### B1 ⭐⭐⭐ 组织层级
- **问法**：公司是 ① 单一总部 ② 总部 + 区域分公司 ③ 总部 + 分公司 + 站点 ④ 加盟体系？每一层各有几个？
- **为什么问**：决定**权限模型（RBAC 还是 ABAC）、数据隔离方案、是否需要多租户**。
- **不问的代价**：做单租户上线后要拆分组织，等于重写。

### B2 ⭐⭐⭐ 调度模式
- **问法**：调度员 ① 集中在总部 ② 各分公司自调 ③ 平台自动撮合 + 人工干预？
- **影响**：决定调度大屏的复杂度、是否需要做自动撮合算法。

### B3 ⭐⭐ 司机构成
- **问法**：① 全职自有司机 ② 外协车队司机 ③ 个体司机，比例如何？司机平均年龄/学历？是否会用智能手机？
- **为什么问**：司机 APP 的复杂度、是否需要语音播报/大字模式、培训成本。
- **不问的代价**：APP 做得太复杂，老司机用不来。

### B4 ⭐⭐ 仓库管理员配置
- **问法**：每个仓库有几个仓管？是否需要 PDA 扫码？文化程度如何？
- **影响**：WMS 模块和 PDA 端的设计简繁度。

### B5 ⭐⭐ 客户端需求
- **问法**：是否让货主/客户：① 自助下单 ② 实时追踪货物 ③ 查温度曲线 ④ 自助开票 ⑤ 评价投诉？
- **影响**：是否要做客户 Web / 客户小程序 / 客户 APP，是后期还是 MVP。

### B6 ⭐ 客服与售后
- **问法**：是否有专门客服岗？投诉处理流程？是否需要工单系统？
- **影响**：是否要做工单 / IM 模块。

## C. 功能范围与优先级（8 题）

### C1 ⭐⭐⭐ MVP 必须功能
- **问法**：如果只给你 6 周时间上线第一版，**哪些功能必须有**？（请按优先级排序，前 5 名）
- **为什么问**：避免功能堆砌，确保 MVP 能上线产生价值。
- **建议清单（让朋友勾选/排序）**：[ ] 下单　[ ] 派车　[ ] GPS 在途　[ ] 温度监控　[ ] 报警　[ ] 签收　[ ] 结算　[ ] 报表

### C2 ⭐⭐ 可延后功能
- **问法**：哪些功能"有当然好，没有也能上线"？
- **典型**：BI 大屏、自动撮合、客户 APP、电子发票、合规对接、智能定价

### C3 ⭐⭐ 计价模型
- **问法**：怎么算运费？① 按公里 ② 按重量 ③ 按体积 ④ 按温区 ⑤ 按订单类型 ⑥ 套餐价 ⑦ 合约价？有几种计价规则？
- **不问的代价**：成本与结算模块返工最频繁的根源。

### C4 ⭐⭐⭐ 派车规则
- **问法**：派车是 ① 完全人工 ② 系统推荐 + 人工确认 ③ 完全自动？推荐时考虑哪些因素（距离 / 空载率 / 司机评分 / 路线相似度 / 温区匹配）？
- **影响**：决定是否要写撮合算法、是否要接外部路径规划 API。

### C5 ⭐⭐ 电子运单/签收
- **问法**：需要电子运单（符合交通运输部「道路货运电子运单」规范）吗？签收方式：纸质签字 / 电子签 / 拍照 / 短信验证码？
- **影响**：是否需要对接电子运单系统、电子签章服务。

### C6 ⭐⭐ 财务对账
- **问法**：是否需要 ① 客户对账单 ② 司机/车队结算单 ③ 油卡管理 ④ 发票管理 ⑤ 应收账款？
- **影响**：财务模块的复杂度、是否对接金蝶/用友 ERP。

### C7 ⭐⭐ 报表需求
- **问法**：日常/周/月/年需要看哪些报表？最关心的 5 个指标？需要导出 Excel/PDF 吗？
- **建议指标**：在途数、超温率、准点率、油耗、人均效能、车均效能、客户 SLA 达成率

### C8 ⭐ 司机绩效
- **问法**：是否要做司机评分？考核维度（准点率/超温次数/客户评价/油耗/出勤）？分数挂钩薪资吗？
- **影响**：HR/绩效模块是否在范围内。

## D. 冷链业务专项 ⭐⭐⭐（10 题，最关键）

### D1 ⭐⭐⭐ 服务温度区间
- **问法**：日常涉及哪些温区？请全部列出。常温(15-25℃) / 恒温(10-15℃) / 冷藏(0-7℃) / 冰鲜(-2~0℃) / 冷冻(-18℃) / 深冷(-25℃) / 超低温(-60℃ 疫苗)？
- **不问的代价**：温度区间没覆盖到，硬件选型/报警阈值全错。

### D2 ⭐⭐⭐ 温度采集间隔
- **问法**：温度数据 ① 每多少秒/分钟上报一次？② 实时报警是否需要更高频？③ 平台存储保留多久？
- **为什么问**：决定**数据库容量**（1 辆车 1 分钟 1 条，100 辆车 1 年 ≈ 5256 万条）和**通讯流量成本**。

### D3 ⭐⭐⭐ 超温报警规则
- **问法**：超过设定温度 ① 多少度？② 持续多长时间？③ 才触发报警？是否分级（黄警/红警）？
- **典型**：医药冷链 8℃ 持续 30 分钟必报；生鲜可放宽到 60 分钟。

### D4 ⭐⭐⭐ 报警通知方式
- **问法**：报警要通知 ① 谁（司机/调度/客户/客户的客户）？② 通过什么（APP 推送/短信/电话语音/钉钉/企微/微信）？③ 多长时间内必须响应？
- **不问的代价**：错过报警 = 货损 = 索赔。

### D5 ⭐⭐ 预冷管理
- **问法**：车辆装货前是否需要预冷？需要预冷到什么温度才允许装货？是否要在系统里强制校验？
- **影响**：派车流程多一道关卡。

### D6 ⭐⭐ 装卸断链管理
- **问法**：装卸过程必然短暂"温度断链"，业务上如何要求？① 整体作业时长限制 ② 关门后多久内必须回温 ③ 还是不管？
- **影响**：报警逻辑要做"装卸窗口豁免"。

### D7 ⭐⭐ 多温区运输
- **问法**：是否有"一车多温区"（如同一辆车前段冷藏后段冷冻）需求？比例多少？
- **影响**：车辆/订单模型要支持温区分段。

### D8 ⭐⭐ 货损处理流程
- **问法**：发生温度异常或货损后，公司目前流程是？① 谁负责定责 ② 索赔金额计算依据 ③ 是否需要系统留痕证据链？
- **影响**：追溯模块的设计深度、是否要做合规留痕（GMP/GSP 用）。

### D9 ⭐⭐⭐ 温度数据合规要求
- **问法**：温度数据需要保留多少年？是否需要不可篡改（区块链/电子签名）？是否要应对审计/检查？
- **典型**：药品冷链温度记录要保留 **不少于 5 年**且不可篡改。

### D10 ⭐⭐ 突发情况处理
- **问法**：车辆故障/事故/堵车导致温度即将失控时，目前的应急流程？需要系统辅助什么？（如自动找最近的中转冷库）
- **影响**：是否要建"应急资源池"模块。

## E. IoT / 硬件 / 集成（7 题）

### E1 ⭐⭐⭐ 车载终端方案
- **问法**：① 已采购品牌（如 G7/中交兴路/赛格/部标终端） ② 计划采购未选型 ③ 计划自研 ④ 让我们推荐？预算单价（500/1000/2000/3000+）？
- **为什么问**：决定**通讯协议（JT/T 808 / MQTT / 私有协议）和接入工作量**。
- **不问的代价**：写完代码发现协议不匹配。

### E2 ⭐⭐⭐ 已有/在用的硬件清单
- **问法**：现在车上有什么设备？请逐一列出品牌型号：① GPS 定位器 ② 温湿度传感器 ③ 车厢门磁 ④ 油量传感器 ⑤ 摄像头/DVR ⑥ 北斗终端？
- **影响**：数据接入难度、是否需要硬件改造。

### E3 ⭐⭐ 通讯方式
- **问法**：终端通讯：4G（哪家运营商资费如何） / 5G / 卫星（远海/无人区）？流量包预算？
- **影响**：数据上报频率上限。

### E4 ⭐⭐⭐ 政府平台对接
- **问法**：是否需要对接以下平台之一/多个？
  - [ ] 全国道路货运车辆公共监管与服务平台（部标 JT/T 808）
  - [ ] 国家药品冷链温湿度自动监测系统（药监局）
  - [ ] 地方食品冷链溯源平台
  - [ ] 疫苗追溯协同平台
- **为什么问**：对接政府平台**必须提前申报、必须用部标硬件**，工作量极大。
- **不问的代价**：上线后被监管要求接入，全部返工。

### E5 ⭐⭐ 地图服务
- **问法**：地图偏好？高德 / 百度 / 腾讯 / 四维图新？是否已有商业 API 配额？
- **影响**：地图 API 费用 + 路径规划/逆地理编码可用性。

### E6 ⭐ ERP / 财务集成
- **问法**：是否要对接 ① 用友 ② 金蝶 ③ SAP ④ 客户的 ERP？同步什么数据（订单/账单/库存）？
- **影响**：是否要做集成中间件。

### E7 ⭐ WMS 扫码方案
- **问法**：仓库出入库识别用 ① 一维码 ② 二维码 ③ RFID ④ 三者混合？批次管理粒度（按托盘/按箱/按 SKU）？
- **影响**：PDA 端硬件选型、WMS 数据模型。

## F. 非功能需求（6 题）

### F1 ⭐⭐⭐ 并发与规模
- **问法**：① 预计 1 年内最大同时在线车辆数？② 调度大屏并发用户数？③ 高峰时段在线司机 APP 数？
- **影响**：服务器选型、是否上消息队列、是否分布式。

### F2 ⭐⭐⭐ 数据保留与归档
- **问法**：① 温度数据保留几年 ② GPS 轨迹保留几年 ③ 业务订单数据保留几年 ④ 是否需要冷数据归档到便宜的存储？
- **影响**：存储成本、是否需要 TimescaleDB/HBase。

### F3 ⭐⭐ 可用性 SLA
- **问法**：系统能接受 ① 99%（年停 3.65 天） ② 99.9%（年停 8.76 小时） ③ 99.99%（年停 52 分钟）？预算敏感否？
- **影响**：是否多机部署、容灾方案。

### F4 ⭐⭐⭐ 安全与等保
- **问法**：① 需要过信息系统等级保护（几级）？② 是否涉及个人信息保护（PIPL）？③ 数据是否能出境？
- **不问的代价**：上线后被要求过等保 2.0，加密改造工作量巨大。

### F5 ⭐⭐ 部署方式
- **问法**：① 公有云（阿里云/腾讯云/华为云偏好）② 私有化（IDC/客户机房） ③ 混合？是否接受 SaaS 模式？
- **影响**：架构方案完全不同。

### F6 ⭐ 网络与办公环境
- **问法**：办公室是否有内网/VPN 要求？是否需要白名单 IP？是否能用国际服务（如 Google 地图）？
- **影响**：部署细节。

## G. 合规与法规（3 题）

### G1 ⭐⭐⭐ 行业合规级别
- **问法**：业务是否涉及以下监管？
  - [ ] 药品 GSP（《药品经营质量管理规范》冷链部分）
  - [ ] 疫苗管理（《疫苗管理法》全程追溯）

  - [ ] 道路货物运输许可
- **不问的代价**：医药/疫苗冷链合规要求是数倍工作量。

### G2 ⭐⭐ 资质管理
- **问法**：是否要在系统里管理 ① 司机从业资格 ② 车辆道路运输证 ③ GPS 监控合规 ④ 公司经营许可证的有效期到期提醒？

### G3 ⭐⭐ 数据审计
- **问法**：是否会有监管部门定期检查温度记录？是否需要一键导出合规报告？

## H. 项目交付（2 题）

### H1 ⭐⭐⭐ 预算与付款

- **不问的代价**：报价没谱、收款没保障。

### H2 ⭐⭐⭐ 交付周期与硬性节点
- **问法**：① 期望多久上线 MVP（4 周/8 周/12 周）？② 是否有硬性时间点（如某客户要求/某展会/某资质评审）？③ 上线后愿意分几个版本迭代？
- **不问的代价**：周期估算失败，背锅。
